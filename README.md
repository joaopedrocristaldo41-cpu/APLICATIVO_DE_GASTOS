# Pork Bank 🐷

Suas finanças pessoais num só lugar: entradas, gastos, contas fixas, parcelas do cartão e metas.

## Como instalar como aplicativo

- **iPhone (Safari):** abra o link → Compartilhar → **Adicionar à Tela de Início**.
- **Android (Chrome):** abra o link → menu ⋮ → **Instalar app**.
- **Computador (Chrome ou Edge):** abra o link → ícone de instalar na barra de endereço.

Depois de instalado, o Pork Bank abre em tela cheia com o ícone do porquinho e funciona até sem internet.

## Seus dados

Tudo fica salvo **só no navegador do seu aparelho**. Nada é enviado para o GitHub nem para outro lugar.
Os extratos e faturas que você importa são lidos no próprio aparelho.
Use **Meus dados → Baixar em CSV** de vez em quando para guardar uma cópia.

**Nunca suba seus extratos ou faturas para este repositório**: ele é público.

## Arquivos

| Arquivo | Para que serve |
|---|---|
| `index.html` | O app inteiro |
| `manifest.webmanifest` | Nome, cores e ícones para instalar como app |
| `sw.js` | Faz o app abrir rápido e sem internet |
| `icon*.png`, `icon.svg`, `apple-touch-icon.png` | Ícones do porquinho |
| `.nojekyll` | Faz o GitHub Pages publicar os arquivos como estão |
